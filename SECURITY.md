# Politique de sécurité

## Versions supportées

Seule la branche `main` reçoit les corrections de sécurité.

## Signaler une vulnérabilité

**Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.**

Signale-la en privé via l'onglet **Security > Report a vulnerability** du dépôt GitHub (signalement privé de vulnérabilité). Indique dans ton rapport :

- la description de la faille et son impact potentiel ;
- les étapes pour la reproduire ;
- la version ou le commit concerné, si possible.

Le mainteneur accuse réception du signalement dans les meilleurs délais, examine la faille, puis coordonne la correction et la publication avec toi avant toute divulgation publique.
